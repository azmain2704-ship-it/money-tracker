What the file should look like

Most UK banks let you export transactions as CSV. The file needs these three columns:

Date,Description,Amount
03/11/2026,TESCO STORES CARDIFF,-23.45
05/11/2026,PART-TIME JOB PAYROLL,412.80
07/11/2026,NETFLIX.COM,-5.99

Negative = money out, positive = money in. Spending is sorted into categories automatically from the description (Tesco → Food, Netflix → Fun). You can't edit the category after import yet, but you can delete and re-add an entry.
